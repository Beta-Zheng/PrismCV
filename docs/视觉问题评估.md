# 简历模板视觉问题评估

> 评估方式：在开发服务器载入内置示例简历，对三套模板的 A4 预览（85% 缩放）逐一截图检查，并结合 `src/components/template.tsx` 的实现核对。
> 评估日期：2026-09-04（对应 commit 3e64d8a 之后的工作区状态）

## 结论摘要

整体版式是健康的：三套模板内容均未溢出 A4 版心（实测日期右缘距页边 48px，与 `--page-pad-x` 一致），日期右对齐、要点缩进、技能标签排版都稳定。当前主要问题集中在**模块分隔线**与**跨模板一致性**两块——最近几次提交在「分隔带」上反复调整（笨重 → 羽化带 → 1px 淡线），最新版本解决了"抢戏"，但引入了"存在感过低"的新问题。

---

## 问题清单

### P1 · 现代/学术模板的模块分隔线几乎不可见（`template.tsx` `SectionRule`）

- **现象**：85% 缩放下，模块标题右侧的延伸线在截图中基本看不出（1px × 0.85 ≈ 0.85px 物理像素，再乘以 8% 不透明度 `color+14`），标题行右侧是一片空白，标题与正文的分区完全靠模块间距撑着。
- **背景**：3e64d8a 之前是 5px 羽化带（墨量 ≈0.53），因"抢戏"被改成 1px + 8%（墨量 ≈0.068，降到原来的 1/8）。方向正确，但矫枉过正。
- **建议**：把不透明度提到 15%~20%（`color+26`~`color+33`），或线高提到 1.5px。按注释里的韦伯定律推算，15% 灰仍处于"相位抖动不可辨"区间（阈值 ≈±5%，抖动 ≈±2%），不会回到粗细不一的老问题，但存在感翻倍。

### P2 · ATS 模板与另两套模板的分隔线语言割裂

- **现象**：ATS 用 2.4px 纯黑实线下边框（视觉很重），现代/学术用 0.85px 8% 淡线（视觉极轻）。来回切换模板时，页面"重量感"跳变明显。
- **说明**：ATS 走 2.4px 是有意为之（`RULE_PX_SOLID × MIN_ZOOM ≥ 2px` 抗相位差，且有 DEV 断言护栏），纯黑粗线也是经典 ATS 的惯例。问题只在**观感落差**，不在各自的正确性。
- **建议**：可接受现状；若要收敛，可把 ATS 线降到 2px 黑（2×0.85=1.7px，需把 MIN_ZOOM 提到 1.0 或接受轻微相位风险），或把现代/学术的线相应加深（同 P1）。

### P3 · row 布局下「地点」单独成行，产生孤行（三套模板共有）

- **现象**：现代单栏与 ATS 中，`location` 在条目标题下方独占一行（如示例中的「上海」「杭州」两个字单独一行），既浪费纵向空间，又让条目头部出现参差的短线。学术模板则把地点并到右侧日期旁（「2021-03 – 至今 上海」），三套模板行为不一致。
- **位置**：`EntryBody` 中 `showLocation && block.location && headerLayout !== "stack"` 分支。
- **建议**：把地点并入右侧日期组（`日期 · 地点`），与学术模板对齐；或并入副标题（`公司 · 职位 · 城市`）。

### P4 · ATS 模板的联系信息分隔符颜色过浅

- **现象**：ATS 标榜"纯黑白"，但邮箱/电话/城市之间的 `|` 分隔符用 `text-ink-300`（浅灰绿），在纯黑正文旁边显得发虚，打印后尤其明显。
- **建议**：ATS 分支下改用 `#333` 或 `#444`。

### P5 · ATS 模板继承全局菱形/箭头要点，偏离「经典」预期

- **现象**：示例简历全局要点样式为菱形时，ATS 模板也渲染旋转 45° 的方块菱形。「经典 ATS」给用户的预期是标准圆点/短横线；菱形符号虽然只是 CSS 绘制（不进文本层，ATS 解析不受影响），但观感上不够"标准"。
- **说明**：这是 `resume.theme.bullet_style ?? "disc"` 的继承逻辑与示例数据（全局 diamond）共同作用的结果，属于设计取舍而非 bug。
- **建议**：ATS 模板下强制 `disc`（或 `ordered`），不让花哨符号进入过筛模板；或至少在切到 ATS 时给出提示。

### P6 · 学术双栏无头像/校徽时头部右侧空置

- **现象**：未上传头像/校徽时（示例的默认状态），学术模板头部只有左侧姓名+职位+联系方式，右侧完全空置，头部视觉偏左、重心不稳。现代单栏有首字母色块兜底，学术模板没有对应的兜底锚点。
- **建议**：给学术模板加一个淡色校徽占位（圆形、8% 主题色底），或把头部改为纯左对齐排版（去掉"右侧应有大元素"的暗示）。

### P7 · 三套模板的姓名字号不一致（2.3em / 2.1em / 2.2em）

- **现象**：现代 2.3em、ATS 2.1em、学术 2.2em。跨模板切换时姓名大小跳变，用户会感知为"内容变了"。
- **建议**：统一为 2.2em，差异交给字重与字距去表达模板个性。

### P8 · 代码卫生：`template.tsx` 中 `SectionRule` 上方残留两代实现的注释块

- **现象**：`SectionRule` 上方并存「5px 羽化带」与「1px 淡线」两份设计说明（约 60 行），参数、墨量推导互相矛盾，后续维护者难以判断哪个是现行方案。
- **建议**：删掉羽化带版本的注释，保留现行 1px 方案的说明与关键推导即可；历史背景交给 git log。

## 不是问题的点（已核实）

- 日期/地点不溢出版心：实测右缘 gap = 48px（85% 缩放屏显 40.8px），与 `--page-pad-x` 精确一致；
- 仅有 start 或仅 end 日期时不会出现前导「–」（`dateRange` 已处理）；
- 空模块、全隐模块不渲染空标题（`SectionBlock` 有守卫）；
- 缩放最小档位 85% 与 ATS 线宽 2.4px 的耦合有 DEV 断言保护，改任一侧启动即报警。
