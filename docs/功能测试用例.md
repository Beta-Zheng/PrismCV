# 功能测试用例

> 覆盖 AI Resume 全部用户可见功能。执行方式分两类：
> - **自动化**：已被 `src/lib/__tests__/` 单元测试覆盖的部分在用例中标注「自动化」；
> - **手工**：需要在浏览器中按步骤执行（可在 `npm run dev` 后配合浏览器开发者工具验证 localStorage）。
>
> 用例编号规则：`模块-序号`。优先级：P0 = 核心路径，P1 = 重要功能，P2 = 边界/异常。

---

实现要点备忘：① Chromium 导出的 PDF 是字形级切分，文本断言前须去空白；② 「微前端」等词同时出现在工作经历正文，不能作为隐藏模块的特征词；③ TMPL-12/EDIT-19 用「备份→改源码→测→恢复→哈希比对」实现，确保工作区零污染；④ 载入示例会直接进入编辑器，无需再点「打开」；⑤ zustand persist 仅在状态变更时写 localStorage，全新浏览器 profile 读状态需做空结构兜底。

至此文档中所有 headless 可执行用例均已自动化；仅 DEV 断言与错误边界两项因需临时改源码，运行 round4 时会短暂修改源文件（脚本自动恢复并校验哈希）。
